In this repository I will do the TOPIC 1 practicals from the module CSY2094 - Systems Design and Development.
The practicals are all based on TOPIC 1 from the first week, where an introduction on Java is given.
Practical 1 : Calculate Average
  A student has taken 4 exams and wants to calculate his average exam score. Write a Java program that calculates the average of 4 hardcoded exam scores.

Prcatical 2: Calculate Total cost of n items
  A shopper wants to buy n items and wants to calculate the total cost of all items, including tax. The tax rate is 8%. Write a java programm that calculates the total cost including tax for n items, each costing 20 pounds;
