# TOPIC 1: OOP Concepts & Intro to JAVA

In this repository I will do the TOPIC 1 practicals from the module CSY2094 - Systems Design and Development.
The practicals are all based on TOPIC 1 from the first week, where an introduction on Java is given.

## PART A

### Practical 1: Calculate Average

  *A student has taken 4 exams and wants to calculate his average exam score.
  Write a Java program that calculates the average of 4 hardcoded exam scores.*

### Practical 2: Calculate Total cost of n items

  *A shopper wants to buy n items and wants to calculate the total cost of all items, including tax.
  The tax rate is 8%. Write a java programm that calculates the total cost including tax for n items, each costing 20 pounds.*

### Practical 3: Calculate the weekly salary of an employee

  *A company wants to calculate the weekly salary of its employees,
  who are paid a base salary of £500 and receive £10 for each hour they work.*

### Practical 4: Calculate monthly savings

  *A person wants to save £1000 in a year.
  They want to know how much money they need to save each month to reach their goal.*

## PART B

### Practical 1: Calculate the average of three numbers

*A java programm that calculates the average of three numbers, using hardcoded numbers.*
